1 Introduction to Python

What is Python, why learn it, and how to get started.

Python is a high-level interpreted programming language renowned for clear syntax.

Hello World:
print("Hello, World!")

Save as main.py and execute using python main.py.

2 Variables & Data Types

Integers, floats, strings, booleans, and conversions.

Store values dynamically:
name = "Alex" → str
age = 21 → int
score = 98.5 → float
passed = True → bool

Type conversion: int("42"), str(100), float("3.14")

3 Operators & Expressions

Arithmetic, comparison, and boolean logic.

Arithmetic: +, -, *, /, // (floor), % (mod), ** (power)
Comparison: ==, !=, <, >, <=, >=
Logic: and, or, not

4 Control Flow (If / Elif / Else)

Conditional decision making in code.

if score >= 90:
    print("Grade A")
elif score >= 75:
    print("Grade B")
else:
    print("Keep practicing!")

5 Loops (For & While)

Iterations, ranges, break, and continue.

For Loop:
for i in range(5):
    print(f"Index: {i}")

While Loop:
while count > 0:
    count -= 1

6 Functions & Scope

Modular code with arguments and return values.

def add_numbers(a, b=10):
    return a + b

result = add_numbers(5) # outputs 15

7 Lists & Tuples

Ordered collections and slicing.

fruits = ["Apple", "Banana", "Cherry"]
fruits.append("Mango")
fruits[1:3] # ['Banana', 'Cherry']
Tuples are immutable: coords = (10, 20)

8 Dictionaries & Sets

Key-value mappings and distinct element sets.

student = {"name": "Yash", "grade": "A"}
print(student["name"])

unique_items = set([1, 2, 2, 3]) # {1, 2, 3}
