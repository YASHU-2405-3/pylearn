# PyLearn Hub 🐍 (GitHub Pages Ready)

An interactive, animated Python learning platform with **in-browser live Python engine**, 30 quiz levels, and mini games.

## 🚀 Instant 1-Click GitHub Pages Setup

1. Create a repository on GitHub (e.g. `pylearn-hub`).
2. Upload this folder's contents (specifically `index.html`).
3. In your GitHub repository:
   - Go to **Settings** → **Pages** (on the left menu).
   - Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`.
   - Click **Save**.
4. In about 30 seconds, GitHub will give you a live HTTPS public link:
   ```
   https://YOUR_USERNAME.github.io/pylearn-hub/
   ```

## 🌐 Put Directly into Google Sites

1. Open your site on [sites.google.com](https://sites.google.com).
2. Click **Insert** → **Embed** (`< >`).
3. In the **By URL** tab, paste your GitHub Pages link:
   `https://YOUR_USERNAME.github.io/pylearn-hub/`
4. Click **Insert**, resize the box to fit your page, and click **Publish**!
